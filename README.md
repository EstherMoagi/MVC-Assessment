#  Event Booking Web Application (MVC)

##  Overview
This is an event booking web application developed using the MVC .
The application allows users to create, view, and manage event bookings in a
structured and organized manner.

##  Features
- Event creation and management
- MVC-based application structure
- Database interaction
- Organized code separation (Model, View, Controller)

##  Technologies Used
- C#
- MVC 
- SQL
- HTML
- CSS
